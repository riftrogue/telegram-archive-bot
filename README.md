# Telegram Archive Bot

A lightweight, highly efficient Telegram bot designed to serve as a personal movie and media archive. This bot allows you to forward movies into a private group, automatically fetches metadata (Title, Year, Language) from TMDB, stores the data in a Supabase database, and provides robust search capabilities.

## Features
- **Auto-Archiving**: Forward any video to the bot. It will extract the IMDb ID, fetch TMDB metadata, re-upload it cleanly (hiding the "Forwarded from" tag), and store it in Supabase.
- **Advanced Search**: Search for any stored movie by Title, Year, or IMDb ID (even full IMDb links). The bot will automatically retrieve the video and send it to you.
- **Editing Capabilities**: Reply to any archived movie with a new IMDb ID (using the `/edit` command) to instantly correct the metadata.
- **Admin Tools**:
  - `/rebase`: Bulk-updates all existing movies in the database with the latest TMDB metadata.
  - `/deleteall`: Wipes the entire database and clears all messages from the Telegram group.

## Prerequisites

1. **Python 3.10+**
2. **Telegram Bot Token** (Get it from [@BotFather](https://t.me/BotFather))
3. **TMDB API Key** (Get it from [TMDB](https://www.themoviedb.org/documentation/api))
4. **Supabase Database** (Create a project on [Supabase](https://supabase.com/))

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/riftrogue/telegram-archive-bot.git
   cd telegram-archive-bot
   ```

2. **Create a virtual environment and install dependencies:**
   ```bash
   python -m venv moviebotenv
   source moviebotenv/bin/activate
   pip install -r requirements.txt
   ```

3. **Configure the Environment Variables:**
   Create a `.env` file in the root directory and add your credentials:
   ```env
   BOT_TOKEN=your_telegram_bot_token
   MOVIE_GROUP_ID=-1001234567890
   SUPABASE_URL=your_supabase_url
   SUPABASE_KEY=your_supabase_anon_or_service_key
   TMDB_API_KEY=your_tmdb_api_key
   ```

4. **Set up the Database (Supabase):**
   In your Supabase SQL Editor, run the following to create the required table:
   ```sql
   CREATE TABLE movies (
       id bigint generated by default as identity primary key,
       chat_id bigint not null,
       message_id bigint not null unique,
       file_unique_id text,
       file_name text,
       title text,
       year integer,
       language text,
       imdb_id text not null unique
   );
   ```

5. **Run the Bot:**
   ```bash
   python bot.py
   ```

## Usage
- **Add a Movie**: Forward a movie file to your `MOVIE_GROUP_ID` chat. Include the IMDb ID anywhere in the caption (e.g. `tt1234567`). The bot will handle the rest.
- **Search a Movie**: Message the bot privately with a movie title, IMDb ID, or IMDb link.
- **Edit a Movie**: Reply to a stored movie message with `/edit tt7654321`.
