# Telegram Movie Archive Bot

A lightweight, personal Telegram bot designed to serve as your private movie and media archive. Just forward your movie files to a private group, and the bot will automatically guess the title, fetch metadata from TMDB, and store everything in a Supabase database for easy search and retrieval.

## ✨ Features
- **Auto-Archiving & Guessing**: Forward any video to the bot. It will automatically parse the file name using `guessit`, fetch TMDB/IMDb metadata, re-upload it cleanly (hiding the "Forwarded from" tag), and store it in Supabase.
- **Advanced Search**: Message the bot privately with a movie title, year, or IMDb ID. It will instantly retrieve the video and send it to you.
- **Manual Overrides**: If the auto-guessing fails, you can add an IMDb ID directly in the caption when forwarding. You can also edit existing entries by replying to them.
- **Admin Tools**: Bulk rebase metadata, delete individual records, or wipe the entire archive clean.

## 🛠️ Prerequisites

1. **Python 3.10+**
2. **Telegram Bot Token** (Get it from [@BotFather](https://t.me/BotFather))
3. **TMDB API Key** (Get it from [TMDB](https://www.themoviedb.org/documentation/api))
4. **Supabase Database** (Create a project on [Supabase](https://supabase.com/))

## ⚙️ Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/riftrogue/telegram-archive-bot.git
   cd telegram-archive-bot
   ```

2. **Create a virtual environment and install dependencies:**
   ```bash
   python -m venv moviebotenv
   source moviebotenv/bin/activate
   pip install -r requirements.txt
   ```

3. **Configure the Environment Variables:**
   Create a `.env` file in the root directory and add your credentials:
   ```env
   BOT_TOKEN=your_telegram_bot_token
   MOVIE_GROUP_ID=-1001234567890
   SUPABASE_URL=your_supabase_url
   SUPABASE_KEY=your_supabase_anon_or_service_key
   TMDB_API_KEY=your_tmdb_api_key
   ```

   **How to get these keys:**
   - **`BOT_TOKEN`**: Go to Telegram, search for **[@BotFather](https://t.me/BotFather)**. Send `/newbot`, choose a name and username, and it will give you the HTTP API Token.
   - **`MOVIE_GROUP_ID`**: Create a private Telegram Group and add your bot to it as an **Admin**. To get the ID, you can forward a message from that group to a bot like **@RawDataBot**, or add **@MissRose_bot** to the group and type `/id`. The Group ID will always start with `-100` (e.g., `-1001234567890`).

4. **Set up the Database (Supabase):**
   In your Supabase SQL Editor, run the following to create the required table:
   CREATE TABLE movies (
       id bigint generated by default as identity primary key,
       chat_id bigint not null,
       message_id bigint not null unique,
       file_unique_id text,
       file_name text,
       title text,
       alternate_title text,
       year integer,
       original_language text,
       file_languages text,
       imdb_id text not null unique
   );
   ```

   **Understanding the Schema (Telegram Endpoints):**
   - **`chat_id`**: The Telegram group ID acting as your storage endpoint.
   - **`message_id`**: The specific endpoint ID of the message containing the video. The bot uses the combination of `chat_id` and `message_id` to directly copy the video file from the group and send it to you privately without needing to download it.
   - **`file_languages`**: Processed via a custom extraction engine designed specifically to parse complex dual-audio and Indian release formats (e.g. `[Hindi - Malayalam]`).

## 🚀 Running the Bot

You have two options for running the bot:

**Option A: Standard Execution (Recommended for testing)**
```bash
source moviebotenv/bin/activate
python main.py
```

**Option B: Background Service / Auto-Restart Loop**
Use the provided bash script to keep the bot alive. It will automatically restart the bot if it crashes.
```bash
source moviebotenv/bin/activate
bash run.sh
```

## 📱 Usage & Commands

**Archiving:**
- **Auto-Detect**: Simply forward a movie file to your `MOVIE_GROUP_ID` chat. The bot will use the file name to guess the movie and archive it.
- **Manual ID**: Forward a movie and add the IMDb ID (e.g. `tt1234567`) anywhere in the caption to bypass auto-guessing.

**Searching:**
- Message the bot privately with a **movie title**, **IMDb ID**, or **IMDb link**. The bot will deliver the file directly to your private chat.

**Editing / Fixing:**
- **Edit Metadata**: If a movie was tagged incorrectly, reply to the stored movie message in the dump group with the correct IMDb ID (or a full IMDb link). The bot will instantly update the caption and the database.

**Admin Commands (Group Only):**
- `/delete` — Reply to a movie message with this command to delete it from both Telegram and the database.
- `/rebase` — Bulk-updates all existing movies in your database with the absolute latest metadata from TMDB.
- `/deleteall` — Wipes your entire Supabase database and clears all bot messages from the Telegram group. (Use with caution!)
